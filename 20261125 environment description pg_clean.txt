environment description pg clean

1. conda install -c gimli -c conda-forge pygimli (includes numpy 1.26.4)
2. conda install -c conda-forge emg3d discretize xarray ipympl h5py tqdm (includes empymod)
3. conda install ipykernel
4. conda export --format=explicit --file=pg_clean.txt
5. copy environment text file to data folder on GSE server "scp pg_clean.txt suzannevannoor@palmyra.citg.tudelt.nl:/palmyra/data/suzannevannoor"
6. in the palmyra data folder (Putty/Linux terminal), check that the txt file is loaded by using "ls" command
7. type "conda create --name pg_clean --file pg_clean.txt -c conda-forge -c gimli
